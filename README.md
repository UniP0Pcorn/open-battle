# open-battle

Godot 4 原生 GDScript 数字桌面对战原型。当前实现本地二维俯视移动沙盒，项目许可证为 **AGPL-3.0-only**，仅第 3 版，不包含“或后续版本”授权。

## 启动

1. 安装 [Godot 4 标准版](https://godotengine.org/download/windows/)（无需 .NET）。基准版本为 **4.5.1**。
2. 在项目管理器点击“导入”，选择本目录 `project.godot`。
3. 打开项目，按 **F6** 运行当前场景，或 **F5** 运行项目。

命令行（将 `godot` 替换为本机 Godot 可执行文件路径）：

```sh
godot --path . --editor
godot --path .
godot --headless --path . --script tests/run_tests.gd
```

无需插件、外部素材、Node.js 或网络服务。工程打开后即可运行；本仓库不附带 Godot 引擎安装包或独立游戏可执行文件。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键选择并拖动底座 | 显示本次直线距离和累计移动额度；松开提交 |
| P / Place Base | 切换放置模式，点击桌面放置底座，可连续放置 |
| Tab / Switch Side | 切换新底座颜色，不限制控制现有棋子 |
| Esc | 取消拖动或退出放置模式 |
| N / New Move Phase | 重置双方所有底座的移动额度 |
| R / Reset Table | 清空修改并恢复初始 10 对 10 底座 |
| T / End Turn | 切换当前操作阵营，只能移动当前阵营的底座 |
| U / Undo Move | 撤销最近一次已提交的移动 |
| Space / 进入射击阶段 | 锁定移动，进入当前阵营的射击阶段 |
| F / 射击最近目标 | 对射程内最近的敌方底座进行一次原型武器攻击 |
| S / 保存 | 保存当前回合、分数、位置、移动额度和伤口到本机存档 |
| L / 加载 | 读取本机最近一次存档 |

桌面横向 60 英寸、纵向 44 英寸。每格 1 英寸，底座直径 40mm，即约 1.5748 英寸。窗口缩放只改变显示，不改变规则单位。

选中底座后，圆环显示剩余移动半径。拖动显示本次移动距离，右侧显示累计值。超过额度、整个底座不能留在桌面内、或落点与其他底座重叠时，预览标红并显示原因；松开后退回原位置，额度不变。合法移动累计消耗额度，多次拖动不能绕过限制。结束回合后，另一方才能操作自己的底座；撤销只影响最近一次已提交的移动。

射击阶段使用 `data/units/custodian_guard.json` 中的可配置测试武器，按攻击次数、命中值、力量、目标韧性和伤害计算结果。被减至 0 伤口的底座会从桌面移除。所有这些数值均为原型配置，不代表任何已核验的官方规则版本。

桌面中央有一个 3 英寸控制半径的目标点。回合结束时，如果当前阵营有底座在目标范围内，就获得 1 分；分数显示在右侧。任务从 `data/missions/control_center.json` 加载，达到任务目标分数后显示完成。军队示例和通用编成校验位于 `data/armies/` 与 `rules/army_validation.gd`。保存文件写入 Godot 的 `user://` 目录，不进入仓库。

## 测试单位与数据

`data/units/custodian_guard.json` 使用 Custodian Guard 名称、40mm 底座和 **6 英寸测试移动额度**。6 英寸是可编辑的原型假设，未按某个官方规则版本核验。本项目不包含官方长篇规则文字、美术、徽记、模型或军表数据库。

## 当前限制

- 仅本地二维沙盒；没有联机、3D 模型、回合权限、保存和撤销。
- 每个底座独立累计移动。尚无多模型单位组织、队形一致性、地形、视线、冲锋、战斗或骰子系统。
- 每次拖动按起点到终点的直线长度计算，不跟随鼠标轨迹；仅检查终点占用，暂不检查路径穿越其他底座或障碍。需要折线移动时分段拖动，各段累计。
- New Move Phase 是手动测试按钮，可随时重置双方额度，不代表正式阶段规则。
- 原型界面为英文，说明文档为中文。窗口逻辑尺寸 1280×860，采用等比例单位绘制；无缩放/平移镜头。
